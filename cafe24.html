카페24 스토어 스토리의 독자는 자사몰(카페24) 운영 셀러입니다. 셀링부스터는 네이버·쿠팡·11번가 대상 분석 도구이므로, "자사몰 + 오픈마켓 병행 판매"를 접점으로 삼는 주제만 유효합니다. 오픈마켓 단독 주제는 독자 적합도가 낮아 조회·앱 유입 모두 떨어집니다.

본 계획의 6편은 전부 자사몰 운영자가 오픈마켓을 함께 볼 때 생기는 질문으로 설계했습니다. 이 기준이 자사 블로그·네이버와의 유사문서 분리선이기도 합니다.

POLICY 발행 정책

레퍼런스 관측(스토리 #6742 · #6700) 기준 · 카페24 스토어 운영 규정은 등록 전 재확인 필요(별첨 B)

CAFE24 스토리 작성 표준

  1. 주제 — 자사몰 셀러의 질문에서 출발함
    • "자사몰만 운영하다 오픈마켓을 보게 될 때" 생기는 질문을 1차 소재로 삼음
    • 오픈마켓 단독 노하우, 플랫폼 입점 절차 등은 제외 — 독자 적합도 미달
    • 카페24 스토리 카테고리 8종 중 가이드 사용팁 활용백서 요즘 트렌드 4종을 주로 사용
  2. 제목 — 질문형 또는 콜론 구조, 25자 내외
    • 관측 패턴: 「카페24 상품으로 견적서 만들기: 엑셀·PDF 전달까지」(작업+결과), 「광고비 0원으로 AI에게 내 쇼핑몰 어필하기」(혜택 선행)
    • 목표 키워드를 앞쪽에 배치 · 자사 블로그·네이버 제목과 전면 상이하게
  3. 구조 — 질문형 소제목 4~6개 + 즉답 1문장
    • 도입: 자사몰 운영 맥락 2~3문장 → 이 글이 답하는 질문 제시
    • 본문: 소제목마다 결론 먼저, 비교표 1개 이상 포함
    • 마무리: 실행 순서 3~5단계 요약
  4. 분량 — 공백 포함 2,000~2,500자
    • 관측상 기존 스토리는 800~1,000자대가 다수 → 분량만으로도 체류시간·검색 노출 우위 확보 가능
    • 자사 블로그(4,000~6,000자)보다 짧게, 네이버(2,500~3,500자)와 비슷한 수준
  5. 간접 홍보 — 본문 직접 세일즈 금지, 서비스 언급 1회
    • 상세 페이지 하단에 「스토리 관련 상품」 앱 카드가 자동 노출되므로 본문에서 팔 필요 없음
    • 본문 언급은 "이런 수치는 ○○에서 확인할 수 있다" 수준 1회 · 기능 나열·가격 안내 금지
    • 앱 카드 연결을 전제로 본문은 정보 완결성에만 집중함
  6. 유사문서 방지 — 3채널 각도 분리
    • 자사 블로그=오픈마켓 실무 / 네이버=1인칭 경험담 / 카페24=자사몰 운영자 관점
    • 같은 주제군이라도 전제·예시·표 구성을 전면 다르게 · 자사 원본과 2주 이상 시차 유지
    • 이미지는 전용 재캡처 — 자사·네이버 버전과 동일 파일 사용 금지

Highook 생성·워싱 파이프라인 (본편과 동일)

  1. STEP 1 — 하이훅 초안 생성
    • 주제 키워드는 아래 계획표의 「하이훅 주제 키워드」 컬럼 사용 · 국가 한국 고정
    • 유형은 전건 정보 — 카페24 스토리는 간접 홍보가 원칙이므로 상업 미사용
  2. STEP 2 — Claude 워싱(카페24 전용 기준)
    • 자사 CMS 포맷(키워드 링크 20개·인라인 스타일·칩 블록) 적용 금지 — 카페24 에디터가 이식하지 않음
    • 통계·수치는 1차 출처 검증 후 텍스트 출처 표기 · 외부 리포트 직접 인용 보류 기준 동일 적용
    • 산출물: 붙여넣기용 본문 1파일(제목·카테고리·이미지 ALT는 주석 분리)
  3. STEP 3 — 카페24 스토어 등록
    • 스토리 카테고리 지정 → 본문 등록 → 이미지 직접 업로드 → 관련 앱 연결 확인
    • 등록 후 노출까지 검수 절차가 있는지 1편 등록 시 확인 필요(별첨 B)
  4. STEP 4 — 발행 후 관측
    • 스토리 조회수·좋아요, 앱 상세 유입 증감을 2주 단위로 기록
    • 구글에서 site:store.cafe24.com + 목표 키워드로 색인 확인
