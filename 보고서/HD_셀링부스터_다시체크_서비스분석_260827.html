2026-08-27 (목)|커머스커넥트실 셀링부스터팀 이슬기
Summary

셀링부스터 · 다시체크 서비스 비교 요약

  • 경쟁 현황'다시체크'는 당사 '분석' 기능과 직접 중복되는 주요 경쟁 서비스임
  • 분석 결과기업 규모 대비 쿠팡 분석 및 판매량 추정 기능에서 비교 우위 보유
  • 대응 방향기업 규모와 무관하게 핵심 기능 단위의 전략적 벤치마킹 필요
서비스 개요
  • 네이버 광고 API와 쿠팡 크롤링 기반의 키워드·시장 분석 도구
  • 심층 데이터는 대부분 크롬 확장프로그램에 의존
공통점
  • 키워드 검색량·경쟁강도·연관·트렌드·광고 지표는 양사 모두 네이버 광고 API 사용
  • 기초 데이터는 동일
다시체크 강점
  • 쿠팡 심층 지표(로켓 비중·PB 판별·Wing 페이지뷰) 제공
  • 상품별 판매량·매출 추정
다시체크 리스크
  • 확장프로그램이 서비스의 절반을 차지, 커머스 채널에서 크롤링 정책 변경 시 핵심 기능 일괄 중단 가능
  • 운영 주체 미공개
셀링부스터 강점
  • 11번가 포함 3채널 지원
  • 부가 기능: AI 상품명 점검, 최적가 추천, 판매 실행(셀링스파크)
  • 편의 요소: 모바일 앱(9월 출시), 무료 요금제, 운영 주체 신뢰도
후속 과제

① 판매량 추정 기능 실험
② 상품 정보 수집 체계 안정화 및 쿠팡 분석 고도화
③ 앱 서비스 및 셀링스파크 등 후속 서비스 차별화
