셀링부스터 자사 블로그 & 네이버 블로그

커머스커넥트실 셀링부스터팀 자사 주 5회 · 월수금 본편 + 화목 아이템 네이버 파생 주 3회 · 재집필 시즌 콘텐츠 2~3주 선행 기준일 2026. 8. 25
자사 블로그(sellingbooster.io)와 네이버 블로그의 발행 원칙을 한 문서로 통합한 운영 표준입니다. 두 채널은 하이훅 초안 1회 생성 → 채널별 워싱 2회(셀부/네이버) → 각 채널 발행 구조로 운영하며, 네이버판 워싱 시에는 연관 셀링부스터 콘텐츠 링크·언급을 포함합니다(색인·인용에 방해되지 않는 선). 네이버 기준은 SEO실 GEO 구조 점검(8/21) 반영 v2가 최신입니다.

2하이훅 주제 키워드 입력 가이드

하이훅이 검색량·연관 키워드 탐색을 자동 수행 — 입력이 짧고 정확할수록 구조 품질이 올라감

입력 — 제목이 아닌 핵심 명사구 2~4어절만 넣음
  • 예: 제목 "초보 셀러를 위한 상품 소싱 전략 3가지" → 입력은 온라인 상품 소싱
  • 검색 의도가 담긴 명사구 기준 · 수식어·조사 제거
설정 — 국가 '한국' 고정, 유형 기본 '정보'
  • '상업': 자사 서비스가 본문 중심인 편만 (기능 가이드 등)
  • '리뷰': 화·목 아이템 비교 편에 활용 (미니 건조기, 전기요 등)
생성 전 — 6단계 '수정' 버튼으로 셀링부스터 섹션·CTA 추가
  • 4단계 키워드 리스트에서 서브 타깃 키워드(발행 계획표 비고) 포함 여부 확인
생성 후 — 워싱 표준 워크플로 적용 (아래 3항)
  • 하이훅 생성물은 초안 — 통계 검증·포맷 변환 없이 직발행 금지

4이미지 삽입 워크플로 (③·⑦ 워싱 공통)

셀링부스터 실제 서비스 화면 캡처 첨부를 권장 — 원본성 확보(유사문서 대응) · 제품 수치 차별화 · AI 생성 일러스트보다 신뢰도 우위

STEP 1 — 하이훅 초안 생성 페이지에서 이미지 추가 후 저장
  • 워싱 단계에서 이미지를 새로 넣어야 할 때는 하이훅 초안 페이지에서 직접 추가·저장한다 (별도 호스팅 불필요)
  • 캡처 대상: 키워드 분석 리포트 · 최적가 추천 · AI 상품명 생성 · 셀링플래너 등 해당 단락이 설명하는 실제 화면
STEP 2 — 저장된 이미지 경로만 복사
  • 추가된 이미지의 https://highook.com/image/…webp 경로를 복사한다
STEP 3 — 워싱 프롬프트에 경로 전달, alt 유지·경로만 교체 요청
  • 워싱본의 alt는 그대로 두고 src 경로만 교체하도록 요청 (alt는 SEO 대체 텍스트라 유지가 원칙)
  • 이미지 배치 위치가 애매하면 먼저 배치 제안을 받고 확정한다
① 배치 제안 요청 예시해당 단락 다음에 셀링부스터 서비스 이미지 스샷을 넣는 것 어떻게 생각해?
② 경로 교체 요청 예시추가한 이미지의 링크를 전달할게! alt는 유지하되 경로를 바꿔줘 <img src="https://highook.com/image/7f691f1d-32f9-4a60-8804-170e4ccf6722.webp" alt="7f691f1d-32f9-4a60-8804-170e4ccf6722.webp" wrapperstyle="display: flex">
③ 이미지 주변 문맥·연관 콘텐츠 연결 문구 예시도구별 화면과 수치 예시까지 자세히 보고 싶으시면 스마트스토어 키워드 분석 5분 가이드에 정리되어 있고, 검색량과 경쟁강도를 한 화면에서 확인하시려면 셀링부스터 키워드 분석에서 무료로 검색해 보실 수 있어요.
채널별 처리 차이 — 셀부는 하이훅 경로를 그대로 유지(referrerpolicy="no-referrer" + border-radius 50px, UI 스크린샷은 0px). 네이버는 핫링크가 불가하므로 같은 이미지라도 내려받아 재저장(리사이즈 90% 또는 jpg 재인코딩) 후 직접 업로드하고, 파일명·ALT를 자사 버전과 겹치지 않게 전량 변경한다(대조표 필수).

5셀링부스터 블로그 발행 방식 (어드민 상세)

워싱 완료 HTML → 어드민 블로그 게시판 ↗ 등록 · HTML 소스 모드 붙여넣기 후 뷰 전환 없이 저장이 핵심

STEP 1
글쓰기 진입 · 카테고리 선택
지식 / 이용사례 / 뉴스룸 / K트렌드 매거진 중 계획표상 카테고리 선택
STEP 2
제목 입력
CMS가 제목을 h1으로 자동 출력 — 본문 HTML에 h1 포함 금지(중복 h1 방지)
STEP 3
HTML 소스 모드 전환
HTML 파일을 텍스트 에디터로 열어 소스 전체 복사(브라우저 렌더링 화면 드래그 복사 금지) → 에디터 소스(HTML) 모드에 붙여넣기
STEP 4
뷰 전환 없이 저장
비주얼 편집 모드로 전환하면 인라인 스타일이 소실됨 — 붙여넣기 후 그대로 저장
STEP 5
렌더링 검수
표 열 비율·이미지 라운드·키워드 링크 색상(#00B1BD)·키워드 칩 블록 정상 출력 확인
STEP 6
발행 · 색인 요청
발행 후 구글 서치콘솔·네이버 서치어드바이저에 URL 색인 요청
  • 수정 시에도 소스 모드 사용 — 발행 후 본문을 고칠 때 비주얼 모드로 열면 스타일이 깨지므로 반드시 소스 모드에서 수정
  • 이미지 경로 — 하이훅 경로 그대로 유지 · referrerpolicy="no-referrer" 누락 시 이미지 미표시 발생
  • 키워드 링크 — 상품성 키워드만 첫 등장 1회, 최대 20개 · 링크 오작동 시 공백 %20 인코딩 확인

6네이버 발행 표준 v2

SEO실 GEO 구조 점검(8/21) 반영 — "워싱"이 아닌 "재집필" · 자사 워싱 표준(3항)의 키워드 링크 20개·인라인 스타일 규칙 적용 금지

STEP 0 — 검증 통과 키워드만 착수함
  • 검색량: 1일 방문자수 연동 — 신규 채널 100~500 / 300~1,000명 500~1,500 / 1,000명+ 1,500+
  • 경쟁강도: 웨어이즈포스트 '비율' 5 이하 우선, 최대 100 이하
  • SERP 확인: AI 브리핑 노출 + 블로그 인용 여부 / 상위 5위 내 3레벨↑ 채널 4개 이상이면 제외
  • 정보성 키워드 우선
KPI — AI 브리핑·AI탭 인용수 1순위 (방문자수·순위는 후순위)
  • 도입 = 브리핑용: 정의문 1문장 + 핵심 불릿 3~4개(설명체) → 경험담 연결
  • 본문 = AI탭용: 비교표(표째 인용, 최우선) → 번호 단계 → 주의 리스트 → 이후 단계
  • FAQ = 양 지면 공용
구조 — 질문형 소제목 5~7개 + 즉답 1문장, 본문 2,500~3,500자
  • 소제목: 메인 키워드 포함 질문형, 각 400~600자
  • 표 2개 이상 · FAQ 5개 이상(SERP 연관질문 기반)
  • 증량은 독립 완결형 섹션 신설로만 — 중복 서술 증량 금지
링크 — 총 2개 이하 (연관 셀부 콘텐츠 1 + 하단 CTA 1)
  • 워싱 시 연관 셀부 블로그 글을 본문에서 자연스럽게 언급 + 링크 1개 — 다량 아웃링크는 홍보성 판정 요인이므로 상한 엄수
  • 예: https://sellingbooster.io/community/blog/seumateuseutoeo-kiwodeu-bunseok-5bun-gaideu-…
  • 배치: 본문 중반 이후 문맥 삽입(같은 주제를 더 깊게 다룬 글로 안내) · 앵커는 브랜드명 나열 대신 서술형
  • AI 추출 블록(정의문·불릿 / 비교표 / 단계 리스트 / FAQ) 안에 링크 금지
  • 인용 극대화 목표 글은 링크 0개 발행 옵션 유지 (인용 획득 글 전건 링크 0 관측)
  • 태그 최대 5개(목표 키워드+브랜드명) · 제품 수치·캡처는 발행 직전 실화면 재검증 필수
유사문서 — 하이훅 초안에서 독립 집필(자사 글 복제 아님)
  • 네이버판은 자사 원본을 옮기는 게 아니라 같은 초안에서 별도 집필 — 제목·구성·문체 전면 상이
  • 같은 주제를 양 채널에 낼 때만 자사 색인 완료 + 2주 시차 적용 (원본 페널티 역전 방지)
  • 연관 글 언급은 인용·안내 형태로 — 원문 문장 복사 금지
  • 이미지: CMS 재사용 가능 — 재저장(리사이즈 90%/jpg 재인코딩) + 파일명·ALT 전량 변경(대조표) + 직접 업로드
  • AI 이미지 고지 유지 · 영상 자체 업로드 15~30초 1개 목표
검증 근거: SEO실 실험 채널 7건 중 AI탭 5건·브리핑 4건 인용 관측 — 월 검색량 100~500 저경쟁 표본의 경향치로, 인용을 보장하지 않으며 검색 시점마다 변동됨. 시차 미준수 시 자사 원본이 유사문서 페널티를 받는 역전 리스크가 최악의 시나리오.

7네이버 발행 프로세스 개정

자사 글 재집필이 아닌 하이훅 초안 → Claude HTML 워싱 → 발행 직결 · 산출물은 검토용 스타일 HTML(시안) + 발행용 작업 지시서 2종 세트

STEP 0
키워드 검증
검색량·경쟁강도·SERP 통과 키워드만 착수 · 시즌 편은 시즌 2~3주 전 발행이 되도록 역산
STEP 1
하이훅 초안 생성
검증 통과 키워드로 초안 생성 · 6단계 구조 수정에서 질문형 소제목·비교표 자리 확보
STEP 2
Claude HTML 워싱
네이버 워싱 채팅에 초안 전달 → 발행 표준 v2(6항) 구조로 재구성 · 경어체 전환 · 제품 수치 실화면 재검증 · 이미지 추가는 4항 워크플로
STEP 3
연관 콘텐츠 연결
같은 주제 셀부 블로그 글을 본문에서 언급 + 링크 1개(중반 이후 문맥 삽입) · 총 링크 2개 이하 · AI 추출 블록 내 삽입 금지
STEP 4
네이버 발행
스마트에디터 등록 — 상세 절차는 아래 8항 네이버 블로그 발행 방식 참조
STEP 5
인용 관측
1~2주 후 AI 브리핑·AI탭 인용 확인(시점 변동 → 주기 재관측) · 미인용 시 불릿·비교표·FAQ 보강 후 재저장 · 월간 인용수 집계
같은 주제를 양 채널에 낼 경우에만 자사 원본 색인 완료 + 2주 시차를 적용한다(유사문서 역전 방지). 네이버 단독 주제이거나 초안 단계부터 구성이 다른 글은 시차 없이 발행 가능 — 연관 글 링크·언급은 인용 형태로만 처리한다.

8네이버 블로그 발행 방식 (스마트에디터 ONE 컴포넌트 조립)

HTML 붙여넣기가 아니라 작업 지시서의 블록을 순서대로 조립하는 방식 · 워싱 산출물은 검토용 스타일 HTML + 발행용 작업 지시서 2종 세트로 받는다

↗📄 작업 지시서 샘플 — 스마트스토어 키워드 분석 툴바 매핑 · 붙여넣기 블록 · 표 TSV · 이미지 ALT 목록 · 태그 · 체크리스트
가장 흔한 실수 — 툴바의 { } 소스코드는 HTML 편집기가 아님. 프로그래밍 코드를 회색 박스에 그대로 보여주는 컴포넌트라, 여기에 HTML을 넣으면 태그가 글자로 노출되고 색인에도 잡히지 않는다. 네이버는 HTML 태그가 아니라 에디터 컴포넌트 구조를 색인하므로, 소제목·표·인용구 컴포넌트로 조립하면 GEO 구조 점수는 동일하다.
STEP 1
제목 입력
지시서 3-1의 제목을 제목 입력란에 붙여넣기 · 본문에 제목 중복 입력 금지
STEP 2
본문 블록 순서대로 붙여넣기
지시서 3-3의 블록을 위에서부터 순서대로 · Ctrl+Shift+V(서식 없이)로 붙여야 잔여 서식이 안 딸려옴
STEP 3
소제목 컴포넌트 지정
[소제목] 표시된 줄을 드래그 → 좌측 드롭다운 본문 → 소제목 · 글자 크기만 키우면 색인 단위로 인식되지 않음
STEP 4
표 삽입 (TSV)
지시서 3-2 블록 복사 → 시트에 붙여넣기 → 다시 복사 → 툴바 표 삽입 후 첫 칸에 붙여넣기 · 표를 이미지로 만들면 AI 인용 경로가 사라짐
STEP 5
이미지 업로드 + ALT
CMS 원본 재저장(리사이즈 90%/jpg 재인코딩) → 지시서 3-4 파일명으로 변경 → 툴바 사진 업로드 → 이미지 클릭 후 대체텍스트 입력
STEP 6
링크·구분선·영상
링크는 문구 드래그 → 툴바 링크 · 마무리 직전 구분선 1회 · 기능 시연 영상 15~30초 자체 업로드(권장)
STEP 7
태그 입력 · 발행
지시서 3-5 태그를 태그 입력란에 최대 5개 · 체크리스트 확인 후 발행

툴바 매핑

지시서 표기에디터 조작비고
[소제목]드롭다운 본문 → 소제목색인 단위 — 크기만 키우지 말 것
[본문]본문 유지, 크기 16폰트 나눔스퀘어 그대로(원고 시안과 일치)
[굵게]B정의문·즉답 문장에만
[불릿]·[번호]정렬 옆 목록 아이콘번호 목록도 같은 버튼
[표]툴바 표TSV 붙여넣기 권장
[구분선]툴바 구분선마무리 직전 1회
[이미지]툴바 사진업로드 후 이미지 클릭 → 대체텍스트 입력
  • 발행 전 체크 — 소제목 전건 컴포넌트 지정 · 표가 이미지가 아닌 표 컴포넌트 · 링크는 마무리 문단 2개뿐 · 이미지 전량 ALT 입력 · 제품 수치 실화면 일치 · 태그 5개 이하 · 제목 본문 중복 없음
  • 이식되지 않는 요소 — div·class·인라인 스타일·키워드 링크 20개·핵심 키워드 칩 블록은 무효 · 해시태그는 본문 텍스트 단락 + 태그 입력란으로 이원 처리
  • 이미지 파일명·ALT — 자사 버전과 겹치지 않게 전량 변경(지시서 3-4 대조표 기준) · 셀부 실캡처는 해당 문단 바로 뒤에 배치

9컴플라이언스 · 수치 검증 원칙 (양 채널 공통)

위반 시 콘텐츠 신뢰도·채널 지수에 직접 타격 — 발행 전 필수 점검

  • 통계는 1차 출처만 — 통계청·식약처·관세청·농림축산식품부 등. 자사판은 원출처 아웃바운드 링크, 네이버판은 링크 없이 텍스트 출처 표기
  • 조건부 리포트 인용 주의 — 나스미디어 등 배포 보고서는 자체 조사 데이터의 상업 게재 시 사전 동의 필요. 외부기관 출처 데이터는 원출처에서 재확인 후 원출처 기준으로 인용
  • 미검증 수치 금지 — "전환율 200%" 등 근거 없는 수치 주장 사용 불가 · 제품 수치(검색량·CPC 등)는 발행 직전 실화면 재검증
  • 표현 기준 — 현재 전 기능 무료 사용 ("평생 무료·영구 무료" 금지) · 경쟁사 가격·통계 직접 명기 금지
  • AI 활용 고지 — AI 생성 이미지 사용 시 고지 문구 유지 · 본문에 자체 데이터·실캡처 등 원본 요소 필수 포함

10운영 원칙 · 발행 전 체크

일정·품질 관리 공통 수칙 — 상세 일정은 셀링부스터 블로그 발행 계획 ↗ 참조

  • 2~3주 선행 원칙 — 시즌·이벤트 콘텐츠는 검색 수요 상승 전 발행 (예: 추석 편 9월 초 배치, 11월 이벤트는 10월 중하순 발행)
  • 연휴 스킵 — 검색 트래픽 저조 구간(추석 9/24·9/25·9/28)은 발행 스킵, 직전 슬롯에 시즌 체크리스트 배치
  • 역할 분리 — 같은 시즌 주제라도 본편=키워드 전략, 화목=아이템 분석으로 앵글 분리 · 네이버판은 시차에 맞춰 앵글 자체 전환(사전 준비 → 막판 수요/결산)
  • 내부링크 크로스 — 시리즈 편(3채널·셀링플래너·분석)과 본편↔아이템 편은 상호 내부링크로 연결
  • 유동 슬롯 관리 — 신규 서비스·기능(블로그 마켓·틱톡샵·셀링플래너·TTJ 랭킹) 연계 편은 출시 일정 확정 후 발행, 미출시 시 순연
  • 검증 부하 관리 — 화목 아이템 편은 자사 트렌드 키워드 데이터 중심 구성으로 주 5회 검증 부하 통제
  • 네이버 착수 조건 — 하이훅 초안에서 독립 집필하므로 시차 없이 진행 가능. 단 같은 주제를 양 채널에 낼 경우에는 자사 원본 색인 완료 후 발행(원본 페널티 역전 리스크 차단)
