신규 고도화 기능 — 전체 요약

범위4분기 아젠다 1-B(신규기능)의 후보 기능을 개선 6축 · 기능 9건으로 구조화 — 문제점·방안·기대효과·프로토 예시까지 상세 기획 단위로 전개. 우선순위 확정분이 곧 아젠다 1-B의 실행 범위가 됨
방향수치 나열형 서비스에서 인사이트 · 체험 · 확산 중심 서비스로 전환 — 공유·즉시 분석으로 유입 경로를 새로 만들고, 가이드·실전 코스로 활성 전환을 끌어올리며, 소싱으로 분석→판매 풀퍼널을 완성
일정9월 기획안·우선순위 확정 → 10월 상세 기획·기술검토 → 11월 개발 완료(아젠다 1-B 마감) → 12월 고도화 배포(내부 QA 통과 조건)
실행기능 1(셀러 사용 가이드)은 즉시 착수 — 이슬기 우선 기획안 산출. 나머지는 §3 내역 표의 선결 조건 해소 순으로 순차 진행, 확정 시 Asana 하위 태스크 연동

F1셀러 사용 가이드 UI ③ 온보딩·가이드 우선순위 1 · 즉시 착수

가입 후 "무엇부터 해야 하는지"를 서비스 화면 위에서 직접 안내하는 인터랙티브 가이드. 문서형 가이드가 아니라 사용자 환경 안의 UI로 제공 — 불사자(환경 모션) · 폴센트(메시지 톡) 벤치.

문제
초보 셀러 온보딩·실전 가이드 부재 — 가입 후 활용 경로 없이 이탈. 첫 화면에서 다음 행동(CTA)이 잡히지 않음.
방안
화면 위 코치마크(단계형 툴팁) + 메시지 톡(상황 반응형 안내) 이원 구성. 첫 진입 시 핵심 동선(키워드 검색 → 분석 → 상품명 추천)을 단계 안내하고, 이후에는 상황별 메시지 톡이 다음 행동을 제안. 카카오 오픈채팅·라이브방송 등 커뮤니티 채널로 연결.
기대효과
가입 → 활성 전환·리텐션 개선. 데모 체험형 가이드는 비교 5종 미보유 영역이라 F5(실전 코스)와 묶어 차별화 여지.
선결·검토
우선 CTA 정의 — 마켓연동 vs 상품링크 공유 중 첫 유도 동선 확정 · 카피 톤 검토(참고: 소도몰·국민상회) · 진행 중 스킵/재진입 정책.

쇼핑 동선에서 상품 URL을 공유·복사하는 것만으로 셀링부스터 분석 결과에 도달하는 진입 기능. 폴센트의 '공유하기 → 즉시 등록·추적' UX를 분석 서비스에 차용 — 수집이슈 1안(익스텐션)과 기반 기술 공유.

문제
분석 결과의 외부 공유·확산 경로가 없고, 상품 분석까지의 진입 동선(검색 → 메뉴 → 입력)이 길어 체험 전 이탈 발생.
방안
① 커머스 앱 공유하기(또는 URL 붙여넣기) → 분석 인사이트 요약 도달 → 상세분석 유도 ② 상품 상세 복사 → 즉시 상품 분석(익스텐션 기반) ③ 분석 결과 자체의 공유 링크 발급으로 확산 루프 형성.
기대효과
공유 기반 오가닉 유입 신규 경로 확보 · 진입 마찰 제거로 체험 기반 락인. 비로그인 요약 → 로그인 상세 전환 퍼널로 회원 전환 접점 확대.

F3버티컬 키워드 랭킹 ① 키워드·랭킹 우선순위 3 · 리스트업

3사(네이버·쿠팡·11번가)에 한정된 커버리지를 버티컬·해외 플랫폼으로 확장한 키워드 랭킹. 의류-무신사 · 뷰티-올리브영 · 생활용품-다이소/오늘의집, 해외는 TTJ·라쿠텐 등 — TTJ 연동(아젠다 3) 선행 준비 성격 겸비.

문제
버티컬·해외 커버리지 한정 — 카테고리 특화 셀러(패션·뷰티·리빙)에게 제공할 차별 데이터가 없음.
방안
버티컬 플랫폼별 인기 키워드 랭킹 탭 제공, 네이버 API로 부재한 지표를 버티컬 데이터로 보완(F4 아이템랭킹 연계). 최종 단계에서는 단순 랭킹이 아닌 고객 인사이트 제공으로 승격.
기대효과
버티컬 차별화 · 데이터 커버리지 확대 — 카테고리 셀러의 재방문 사유 확보, 해외 축은 TTJ 연동의 데이터 브릿지.
선결·검토
버티컬 리스트업 확정 · 기존 API / 추가 API 구분 정리(기술 검토) · 플랫폼별 수집 방식·주기 정의.
