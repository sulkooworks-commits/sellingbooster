➕ 새 크롤러 추가 방법 (개발자·기획 공용)
  1. 크롤러/scripts/<id>.py 작성 — collect(params: dict) -> dict 함수 필수. 반환: {"columns": [...], "rows": [...], "meta": {...}}. 단독 실행용 main()도 함께 두면 개발자가 다운로드해 바로 검증 가능 (무신사 스크립트 참고).
  2. 크롤러/crawlers.json의 crawlers 배열에 항목 추가 — id(파일명과 동일) · name · script · params(옵션 UI 자동 생성) · columns(표 컬럼).
  3. 커밋 → 이 페이지에 카드가 자동으로 나타남. 워크플로(crawler-run.yml)·러너(_runner.py)는 수정 불필요.
  4. 수집 데이터는 크롤러/data/<id>/에 latest.json · latest.csv · runs.json · history/로 쌓임.

}
실행 방식: 페이지 버튼 → GitHub API workflow_dispatch → Actions가 _runner.py <id> 실행 → 결과를 크롤러/data/에 커밋 → Pages 반영. 토큰은 이 브라우저 localStorage에만 저장(SEO 모니터링 페이지와 공유).
